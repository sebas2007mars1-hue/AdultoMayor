# Red de Apoyo al Adulto Mayor

Backend desarrollado con Django y Django REST Framework.

## Funcionalidades

- Gestión de usuarios y roles.
- Creación de solicitudes de ayuda.
- Asignación de voluntarios.
- Registro de actividades.
- Seguimiento del estado de las solicitudes.
- Finalización de solicitudes.
- Base de datos SQLite.

## Requisitos

- Python 3.13 o superior
- pip
